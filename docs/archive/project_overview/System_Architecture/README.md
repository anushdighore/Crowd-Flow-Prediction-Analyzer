## 📊 System Overview

The Real-Time Webcam Crowd Counter is a complete end-to-end system featuring:

- **Real-time webcam processing** with WebSocket communication
- **Dual operational modes**: Live webcam and image upload
- **Modern architecture** with FastAPI backend and React frontend
- **VMamba-TMTB deep learning model** for accurate crowd counting
- **Professional UI/UX** with real-time overlays and metrics
